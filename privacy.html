Eben PA privacy policy

Eben PA is a personal assistant used only by Eben Owen. It is not offered to anyone else.

With Eben's permission it reads his own Gmail and Google Calendar to answer his text messages, track follow-ups and suggest calendar changes. It creates drafts, sends emails or changes events only after Eben confirms each action by text.

It keeps a small record of contacts and reminders needed for scheduling. It does not sell, share or use any data for advertising. Google user data is handled in line with the Google API Services User Data Policy, including the Limited Use requirements.

Access can be removed at any time at myaccount.google.com/permissions.
